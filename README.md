# Boosie Network — launch pitch

Static, password-gated pitch page for the *TWINS* launch campaign.

Content is encrypted client-side (AES-GCM-256 / PBKDF2-SHA256, 310k iterations).
The password is shared separately and is not stored in this repository.

`clips/` holds the finished vertical spots for the pre-launch calendar — the same
assets that go out on IG Reels, TikTok, FB Reels and YT Shorts.

Generated by `build_site.py`; do not edit these files by hand.
